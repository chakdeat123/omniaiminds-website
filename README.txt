# OmniAIMinds — GoDaddy Static Website

## Deploy
1. Unzip this package.
2. Open GoDaddy hosting/cPanel File Manager.
3. Go to the domain's document root (commonly `public_html`).
4. Upload the contents of this folder — upload `index.html`, the other HTML files, and the `assets` folder.
5. Make sure `index.html` is directly inside the domain document root.
6. Open your domain.

## Contact form
This starter site is fully static and uses the visitor's email client to prepare an enquiry addressed to:
hello@ominiaiminds.com

If you later want a web form that sends automatically without opening an email client, connect the form to a backend/API or a form service.

## Important content note
The supplied design document contained example-style claims such as historical founding dates, team size, project counts, client counts and performance percentages. Because this is a new company website, this version does NOT publish those unverified claims. Replace/add them only when they are factually true.
